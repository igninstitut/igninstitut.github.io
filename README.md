# Юбилейная HTML-страница: Меиз Сатпаева, 95 лет

Пакет готов для размещения на GitHub Pages.

## Быстрый запуск на GitHub Pages

1. Создайте новый репозиторий, например `meiz-satpaeva-95`.
2. Загрузите в корень репозитория все файлы из этого архива: `index.html`, папку `assets`, файл `.nojekyll`.
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Branch: `main`, folder: `/root`.
6. Нажмите `Save`.
7. Через 1–3 минуты GitHub выдаст публичную ссылку.

## Структура

- `index.html` — основная HTML-страница статьи.
- `assets/css/style.css` — стили.
- `assets/js/main.js` — индикатор чтения при прокрутке.
- `assets/images/` — изображения страницы.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.

## Рекомендации

- При переносе на основной сайт Института можно скопировать содержимое `index.html` в шаблон CMS.
- Изображение для соцсетей указано в meta-теге `og:image`: `assets/images/og-card.jpg`.
- Страница не использует внешние шрифты и библиотеки, поэтому будет работать автономно.
